Gravitational-wave memory: the permanent scar in spacetime

A gravitational wave does not just pass through — it leaves a permanent displacement of test masses. This is the Christodoulou (nonlinear) memory, and it is the cleanest probe of the energy carried away by the waves themselves.

1. What memory is

Linearised gravity says that a passing gravitational wave produces a transient strain h(t) that returns to zero. At nonlinear order, the GWs themselves carry energy, and that energy flux gravitates. The result is a permanent offset in the metric after the wave has passed — a DC (zero-frequency) component that never decays. Test masses separated by a baseline L are displaced by ΔL = hmem L forever (modulo cosmological expansion).

2. The Christodoulou formula

For an isolated source radiating to null infinity, the memory strain is (Christodoulou 1991; Thorne 1992):

$$ h_{\rm mem} = \frac{G}{c^{4} D_{L}} \int_{-\infty}^{\infty} \!\! dt \int \frac{dE_{\rm GW}}{d\Omega'}\, \frac{1 - \cos\theta'}{?} \, d\Omega' $$

In its standard angular form:

$$ h_{\rm mem}(\hat n) = \frac{G}{c^{4} D_{L}} \int d\Omega' \, \frac{dE_{\rm GW}}{d\Omega'} \, \frac{1-\cos\theta'}{1-\cos\theta'} \,\,(\text{geometric kernel}) $$

The precise kernel depends on the observer direction \hat n relative to the radiated energy distribution; the key point is that hmem is proportional to the total radiated energy divided by DL, with a dimensionless angular factor of order unity.

3. Order-of-magnitude estimate for a merger

For a binary black-hole merger radiating a fraction ε = Erad/(M c2) of the total mass, the memory scales as

$$ h_{\rm mem} \;\sim\; \varepsilon\,\frac{G M}{c^{2} D_{L}}\,\mathcal{G}(\iota) $$

where \mathcal{G}(\iota) is an angular factor of order 1–4 that depends on inclination. For GW150914-like parameters (M ≈ 65 M⊙, DL ≈ 400 Mpc, ε ≈ 0.05):

$$ \frac{G M}{c^{2} D_{L}} \approx \frac{65 \times 1.48\,{\rm km}}{400\times10^{6}\,{\rm pc}} \approx 7.8\times10^{-22} $$
$$ h_{\rm mem} \sim 0.05 \times 7.8\times10^{-22} \times 2 \;\approx\; 8\times10^{-23} $$

This is model-derived: the radiated fraction, the inclination and the angular kernel are all inferred from the waveform model, not measured directly.

4. Why memory is hard to detect in LIGO

  • The memory is a near-DC signal; LIGO's sensitivity rolls off below ~10 Hz, and the memory sits at the very bottom of (or below) the band.
  • The SNR scales as hmem/hrms(flow); for GW150914 this is of order a few, i.e. marginal in a single detector.
  • Detector glitches and seismic noise dominate the low-frequency end, so a memory claim requires careful glitch vetting.

5. Where memory is a prime target

  • LISA (mHz band) — supermassive black-hole mergers produce memory strains ~10-19–10-18, well above the instrumental floor; memory is a standard LISA science case.
  • Pulsar timing arrays (nHz) — the stochastic background and individual supermassive mergers leave a memory-like step in the timing residuals; the PTA SNR figure on this site explores the timing residual amplitude.
  • Third-generation ground detectors (Einstein Telescope, Cosmic Explorer) — lower seismic walls push the low-frequency floor down, making ground-based memory detection plausible for stellar-mass mergers.

6. Assumptions and caveats

  • Non-spinning or slowly spinning binaries; spin precession changes the angular distribution of radiated energy and hence \mathcal{G}(\iota).
  • The estimate above uses the total radiated energy; the linear memory (from unbound ejecta) is separate and usually subdominant for compact-object mergers.
  • Cosmological effects: at high redshift the memory is redshifted and diluted; the simple 1/DL scaling assumes a Euclidean-ish local universe.
  • No detection of memory has been claimed to date for stellar-mass mergers; all statements about detectability are forecasts.

7. References

  • Thorne K. S., 1992, Phys. Rev. D 45, 520 — linear and nonlinear memory.
